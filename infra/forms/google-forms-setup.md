# Google フォーム初期構築手順書（W0-1）

本ドキュメントは、Week 0（`W0-1`）でオーナーが無料の Google フォーム 2 種を作成し、メール通知および `/s/{id}` の UGC 通報用プレフィル URL（`REPORT_FORM_URL_TEMPLATE`）を取得するための作業手順書です（根拠: [OQ-15](../../docs/01-product/open-questions.md)、[App Store 審査対策 1.2](../../docs/05-release/app-store-checklist.md)）。

個人メールアドレスを公開せずに問い合わせ・削除請求・不適切コンテンツ通報を受け付けるため、必ず専用または運営用の Google アカウントで作成してください。

---

## 最短手順：Google Apps Script で一括作成する（推奨）

手動で設問をコピー＆ペーストする代わりに、同梱の [create-google-forms.gs](create-google-forms.gs) を Google Apps Script で 1 回実行すると、**フォーム ①・② の全設問と `REPORT_FORM_URL_TEMPLATE` を自動生成**できます。

1. フォームを管理したい Google アカウントで [script.google.com](https://script.google.com/) を開き、「**新しいプロジェクト**」をクリック。
2. [create-google-forms.gs](create-google-forms.gs) の内容をすべてコピーしてエディタに貼り付け、保存（`Ctrl+S` / `Cmd+S`）。
3. ツールバーで関数 **`createKumogakureForms`** を選択して「**実行**」をクリックし、初回のみ権限承認ダイアログ（Google フォーム作成権限）を許可。
4. 実行ログに表示された **公開 URL（フォーム ①）・`REPORT_FORM_URL_TEMPLATE`（フォーム ②）** を控え、両方の **編集 URL** を開いて「**回答**」タブ →「**⋮**」→「**新しい回答についてのメール通知を受け取る**」を ON にしてテスト送信を実施。

> 手動で 1 項目ずつ作成したい場合や、作成される設問の詳細を確認したい場合は、以下の定義を参照してください。

---

## フォーム ①：お問い合わせ・不具合報告フォーム

設定画面（S-08）の「お問い合わせ・不具合報告」、プライバシーポリシー（`/legal/privacy`）、および App Store Connect の「サポート URL」に設定するフォームです。

### 1. 基本設定
- **フォームタイトル**: `雲隠れ（Kumogakure）お問い合わせ・不具合報告`
- **フォーム説明文**:
  ```text
  デジタルデトックスアプリ「雲隠れ（Kumogakure）」へのお問い合わせ・不具合報告・ご要望・データ削除依頼の窓口です。
  原則として個人情報はご入力にならないでください（返信をご希望の場合のみメールアドレスをご記入ください）。
  ```

### 2. 設問定義（そのままコピー＆ペースト）

| # | 質問タイトル | 形式 | 必須 | 選択肢 / 説明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **お問い合わせ種別** | ラジオボタン | 必須 | ・不具合の報告<br>・機能のご要望<br>・隠者プラン（課金・復元）について<br>・不在証明ページの削除依頼<br>・その他のお問い合わせ |
| 2 | **お問い合わせ内容** | 段落（長文回答） | 必須 | 説明: `発生した状況やご要望の内容をお知らせください。不在証明ページの削除依頼の場合は対象 URL またはセッション ID（/s/xxxxxxxxxx の末尾 10 文字）もご記入ください。` |
| 3 | **ご利用端末・iOS バージョン** | 記述式（短文回答） | 任意 | 説明: `例: iPhone 15 / iOS 18.1` |
| 4 | **匿名サポート ID（アプリ設定画面で確認可能）** | 記述式（短文回答） | 任意 | 説明: `アプリ内の「設定」＞「匿名サポート ID」をコピーして貼り付けてください（調査が必要な場合のみ）。` |
| 5 | **ご返信先メールアドレス** | 記述式（短文回答） | 任意 | 説明: `運営からの返信を希望される場合のみご入力ください。`（回答の検証: テキスト ＞ メールアドレス） |

### 3. メール通知と公開 URL の設定
1. フォーム上部の「**回答**」タブを開く。
2. 右上の「**⋮**（その他アイコン）」→「**新しい回答についてのメール通知を受け取る**」にチェックを入れる。
3. （推奨）「**スプレッドシートにリンク**」から管理用シートを作成しておくと履歴追跡が容易になります。
4. 右上の「**送信**」または「**リンク**」アイコンから公開 URL（`https://docs.google.com/forms/d/e/.../viewform`）をコピーして控える。
5. **送信テスト**: 公開 URL をブラウザで開き、テスト送信を行ってメール通知が届くことを確認する。
6. 控えた URL は、Week 3〜4 の iOS `AppConfig` および Week 5 の [法務ドキュメント](../../docs/05-release/legal-drafts.md) に反映する。

## フォーム ②：不在証明ページ 不適切コンテンツ通報フォーム（UGC 対策）

不在証明 Web ページ（`/s/{id}`）下部の「不適切な内容を報告する」リンクから開かれる専用フォームです（App Store Review Guideline 1.2 対応）。タップ元の `session_id` を URL パラメータで自動入力させます。

### 1. 基本設定
- **フォームタイトル**: `雲隠れ（Kumogakure）不適切コンテンツの通報`
- **フォーム説明文**:
  ```text
  不在証明ページ（/s/...）に掲載されている表示名・メッセージについて、公序良俗違反・誹謗中傷・スパム等の問題がある場合はこちらからご報告ください。
  確認のうえ、速やかに該当ページの削除および再発防止措置を行います。
  ```

### 2. 設問定義

| # | 質問タイトル | 形式 | 必須 | 選択肢 / 説明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **対象セッション ID** | 記述式（短文回答） | 必須 | 説明: `報告対象の不在証明 ID（通常は自動で入力されます）` |
| 2 | **通報理由** | ラジオボタン | 必須 | ・誹謗中傷・差別的表現・嫌がらせ<br>・個人情報（氏名・住所・電話番号等）の掲載<br>・スパム・営利宣伝・不審な URL<br>・その他、公序良俗・利用規約に反する内容 |
| 3 | **補足詳細** | 段落（長文回答） | 任意 | 説明: `問題箇所の詳細があればご記入ください。` |

### 3. 事前入力 URL テンプレート（`REPORT_FORM_URL_TEMPLATE`）の取得手順

1. フォーム編集画面の右上「**⋮**（その他アイコン）」→「**事前入力したリンクを取得**」をクリックする。
2. プレビュー画面が開いたら、設問 1「**対象セッション ID**」に **`SESSION_ID_PLACEHOLDER`** と入力し、他の項目は空のまま画面下部の「**リンクを取得**」→「**リンクをコピー**」をクリックする。
3. コピーされた URL は以下のような形式になります:
   ```text
   https://docs.google.com/forms/d/e/1FAIpQLSeXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX/viewform?usp=pp_url&entry.1234567890=SESSION_ID_PLACEHOLDER
   ```
4. 末尾の `SESSION_ID_PLACEHOLDER` を `{session_id}` に置き換えた文字列が **`REPORT_FORM_URL_TEMPLATE`** です:
   ```text
   https://docs.google.com/forms/d/e/1FAIpQLSeXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX/viewform?usp=pp_url&entry.1234567890={session_id}
   ```
5. **メール通知の設定**: フォーム上部の「**回答**」タブ →「**⋮**」→「**新しい回答についてのメール通知を受け取る**」を必ず有効化する。
6. **事前入力＆通知テスト**:
   - 上記テンプレートの `{session_id}` を `test123456` に手動置換した URL をブラウザで開く。
   - 「対象セッション ID」欄に `test123456` が最初から入っていることを確認する。
   - 任意の通報理由を選んで送信し、オーナー宛てにメール通知が届くことを確認する（テスト回答は後で削除可）。
