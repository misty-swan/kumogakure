雲隠れ（Kumogakure）プライバシーポリシー

本サービス「雲隠れ（Kumogakure）」および関連 Web ページ（以下「本サービス」といいます）におけるユーザー情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集・利用する情報と目的

本サービスは、ログインや会員登録（氏名・メールアドレス・電話番号等）を必要とせずにご利用いただけます。本サービスの提供にあたり、以下の情報のみを取り扱います。

  1. 端末生成の匿名識別子（匿名 UUID）：サブスクリプション購入状態の照会、同時利用セッションの重複防止、およびお問い合わせ時の識別。
  2. 不在証明作成時にお客様が任意に入力した情報（表示名・一言メッセージ・選択テーマ・帰還予定時刻・タイムゾーン）：不在証明 Web ページおよび共有用 OGP 画像の生成・表示。不在証明の公開機能（シェア）をご利用になった場合、URL を知る第三者が記載内容を閲覧できるため、氏名・住所・電話番号等の個人情報は入力しないでください。
  3. アプリ内購入情報（購入履歴・サブスクリプション有効状態）：有料プラン（隠者プラン）機能の提供および購入の復元。決済処理自体は Apple Inc. により行われ、運営者がクレジットカード番号等の決済情報を取得することはありません。
  4. 技術的アクセスログ（IP アドレス・リクエスト日時・エラーログ等）：不正アクセス・スパム防止、障害調査、サービスの安定稼働維持。

※ デジタルデトックスの履歴（雲隠れ帳）はお客様の端末内のみに保存され、運営者のサーバーへ長期送信・蓄積されることはありません。

2. データの保持期間および削除

サーバー上に保存された不在証明セッションデータ（表示名・一言メッセージ等）は、発行から 24 時間経過後に自動的に失効（閲覧不可） となり、その後定期処理により物理削除されます。

4. 不在証明ページの検索エンジン非公開

不在証明 Web ページには検索エンジンによるインデックスを拒否する設定（noindex, nofollow）を施していますが、SNS 等へお客様ご自身で投稿された URL や画像の拡散範囲は各 SNS の仕様に従います。
