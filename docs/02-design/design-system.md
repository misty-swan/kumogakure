# デザインシステム & アセット規格書

## 1. ビジュアルコンセプト

**「静謐・和モダン・余白」**
スマホを見る行為そのものから離れさせるアプリであるため、UI は刺激の強い原色やゲーミフィケーション的な派手なバッジを排し、**墨・夜空・朝霧・和紙** を基調とした落ち着きあるトーンで構成します。

## 3. タイポグラフィ

- **iOS アプリ**:
  - **見出し・時刻・ねぎらい文**: ヒラギノ明朝 ProN（システム同梱 `Font.Design.serif`）を使用し、和モダンの情緒を演出。数字（残りタイマー）には `.monospacedDigit()` を適用し、毎秒の横揺れを防ぐ。
  - **UI ラベル・ボタン・設定**: ヒラギノ角ゴシック（システム標準サンセリフ）。
  - **Dynamic Type**: 主要テキストはシステム文字サイズ拡大に対応（タイマー・カード表示部はレイアウト破綻防止のため `minimumScaleFactor(0.7)` を設定）。
- **Web / 動的 OGP 生成（Rust バックエンド）**:
  - 同梱フォント（確定・いずれも SIL Open Font License）: **Shippori Mincho**（しっぽり明朝）をメインフォントとし、珍しい漢字や記号の文字化けを防ぐため **Noto Serif JP** をフォールバックとしてコンテナに同梱・起動時ロードします（[../01-product/open-questions.md](../01-product/open-questions.md) OQ-10）。

## 4. 「霧が晴れる」アニメーション仕様

### 4.1 進捗計算（`progress`）
タイマー残り時間ではなく絶対時刻 `Date` から算出します。

$$\text{progress} = \text{clamp}\left(\frac{\text{now} - \text{startedAt}}{\text{plannedEndsAt} - \text{startedAt}}, 0.0, 1.0\right)$$

### 4.2 霧の視覚減衰モデル
1 枚のベタ塗りではなく、**3 層のレイヤー**を組み合わせることで立体的な霧の晴れ方を表現します（GPU 負荷を抑えるため SwiftUI `Canvas` または軽量シェーダ / 半透明 PNG の平行移動アニメを使用）。

| レイヤー | `progress = 0.0`（開始時） | `progress = 0.5`（中間） | `progress = 1.0`（帰還時） |
| :--- | :--- | :--- | :--- |
| **背景風景のブラー半径** | `16 pt` | `6 pt` | `0 pt`（完全に鮮明） |
| **背景風景の明度調整** | `-0.25`（暗く沈む） | `-0.10` | `0.0`（本来の色調） |
| **遠景霧レイヤー（ゆっくり横流し）** | `opacity: 0.72` | `opacity: 0.35` | `opacity: 0.0` |
| **近景霧レイヤー（逆方向ゆるやか揺らぎ）** | `opacity: 0.85` | `opacity: 0.40` | `opacity: 0.0` |
| **全体シームレス暗幕** | 上下グラデーション強 | 中間 | テキスト可読性用の極薄グラデーションのみ残す |

### 4.3 アクセシビリティ（視差効果を減らす / Reduce Motion）
- `@Environment(\.accessibilityReduceMotion)` が `true` の場合は、霧画像の平行移動アニメーションを停止し、**`progress` に応じた穏やかなクロスフェード（透明度変化）のみ** に切り替えます。
- 画面常時描画によるバッテリー消費を抑えるため、霧の揺らぎアニメは `TimelineView(.animation(minimumInterval: 1.0 / 30.0))`（30fps 上限）とし、バックグラウンド移行時は即座に一時停止します。

## 5. ハプティクス（触覚フィードバック）

iOS 17 の `.sensoryFeedback(...)` を用い、静かな体験を邪魔しない繊細な触覚のみを採用します。

| イベント | Feedback 種別 | 意図 |
| :--- | :--- | :--- |
| 雲隠れ開始（タイマー始動） | `.impact(flexibility: .soft, intensity: 0.7)` | 霧の中へ踏み出す合図 |
| 予定時刻到達・帰還完了（フォアグラウンド時） | `.success` | 穏やかな達成感 |
| 途中帰還・離脱確定 | `.warning`（軽量）またはなし | 罰のような強い振動は使わない |
| 時間チップ・デザイン切替 | `.selection` | 心地よい操作感 |

## 6. コンテンツカタログ & 素材アセット規格

### 6.1 風景アセット（4 種）

| `theme_id` | 日本語名 | プラン | イメージ |
| :--- | :--- | :--- | :--- |
| `misty_mountain` | 霧の山並み | 無料 | 墨絵を思わせる朝霧の連峰と松 |
| `rainy_bamboo` | 雨の竹林 | 無料 | しっとりと雨に濡れる静かな竹林の小径 |
| `moonlit_lake` | 月夜の湖畔 | Pro（隠者） | 水面に満月が映る静謐な夜の湖 |
| `dawn_shrine` | 夜明けの社 | Pro（隠者） | 東雲色の空と静かな鳥居・山社 |

- **解像度・形式**: 縦長モバイル全画面対応 **`1290 x 2796 px`（3x iPhone Pro Max 基準）** または統一アスペクト比 `9:19.5` の HEIC / WebP / JPEG（高品質圧縮、**1 枚あたり 600KB 以下**目標、アプリ容量膨張防止）。
- **文字可読性担保**: 風景の上部（タイマー・見出し）と下部（ボタン）には暗いグラデーション（スクリム）が重なっても破綻しない構図を選定する。
- **調達・権利管理（確定）**: 画像生成 AI により全 4 種のトーンを統一制作し、必要に応じてレタッチ・色調補正を行う。使用ツール・プロンプト・利用規約確認記録をリポジトリ内の素材管理メモに保存する。

### 6.2 環境音 BGM アセット（無音 + 3 種）

| `sound_id` | 日本語名 | プラン | 音質・内容イメージ |
| :--- | :--- | :--- | :--- |
| `none` | 無音 | 無料 | 再生なし |
| `rain` | 雨音 | 無料 | 縁側に降る穏やかな小雨（高域の耳障りな成分をカット） |
| `night_wind` | 夜風 | 無料 | 木々や竹を揺らす柔らかな夜風 |
| `bonfire` | 焚き火 | Pro（隠者） | 遠くでパチパチと爆ぜる囲炉裏・焚き火 |

- **フォーマット**: `.m4a`（AAC-LC）、44.1kHz、ステレオ、128kbps。
- **尺・ループ**: **45〜90 秒** のクロスフェード処理済みシームレスループ音源（継ぎ目のクリックノイズ厳禁、`AVAudioPlayer(numberOfLoops: -1)` で違和感なく繋がること）。

- **容量**: 1 トラック **1.5MB 以下**。
- **調達・権利管理（確定）**: CC0（パブリックドメイン）または商用利用・アプリ同梱可（帰属表示不要推奨）のフリー音源を調達してループ編集し、出典 URL とライセンス証跡を素材管理メモに保存する。

## 7. コピーライティング指針 & マイクロコピー辞典

### 基本トーン
- **丁寧・静か・肯定的**（命令口調「やめなさい」「失敗しました」を一切使わない）。
- 古語を多用しすぎて読みづらくせず、現代の和モダンな文体で統一する。

### 主要マイクロコピー

| シーン | コピー（正本） |
| :--- | :--- |
| 不在証明カード（進行中見出し） | `ただいま、雲隠れ中` |
| 不在証明カード（帰還予定） | `{HH:mm} 帰還予定` |
| 同時雲隠れ人数（1 人以上） | `現在、ほかに {N} 人が雲隠れしています` |
| 同時雲隠れ人数（0 人時） | `いま、深い静寂が広がっています` |
| 離脱 10 秒猶予警告通知 | `霧が濃くなり始めています。10秒以内に戻ると続けられます。` |
| 帰還完了見出し・本文 | `おかえりなさい。{時間} の静寂を得ました。` |
| 途中帰還（手動キャンセル） | `雲の中から戻りました。また一息つきたくなったらお越しください。` |
| 離脱リセット | `霧が深くなりました。深呼吸して、またいつでも始められます。` |
| 完了ローカル通知 | `霧が晴れました。おかえりなさい。` |
| 無料ユーザー 7 日以前ロック | `これより先の雲隠れ帳は「隠者プラン」で開けます` |

## 8. アクセシビリティ要件

- すべてのアイコンボタン（設定、雲隠れ帳、ミュート、画面オン維持、閉じる）に日本語の `.accessibilityLabel` と `.accessibilityHint` を設定する。
- カウントダウンタイマーは 1 秒ごとに VoiceOver が読み上げ続けないよう、`accessibilityElement` を分離または更新頻度制御（`.accessibilityLabel("残り時間 25分")`）を行う。
- 鍵マーク（Pro 限定）は色だけでなくアイコン＋テキスト（「隠者」）の両方で識別可能にする。
