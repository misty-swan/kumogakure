## 1. Apple Developer / App Store Connect 初期設定（Week 4〜5 実施）

Week 1〜4 の開発中は費用ゼロでシミュレータ・`.storekit` ローカル検証を行い、実装完了の目処が立つ **Week 4〜5** で登録・設定を進めます（Small Business Program の承認リードタイムを考慮し、Week 4 での登録開始を推奨）。

- [ ] **Apple Developer Program 登録**: 年額 99 USD。個人/法人確認完了（Week 4〜5）。
- [ ] **Apple Small Business Program 申請**: 手数料 30% → **15%** 適用申請（Developer 登録完了直後に申請）。
- [ ] **App ID 登録**: 仮 Bundle ID `app.kumogakure.ios` 等の空き確認のうえ本登録し、`AppConfig` に反映（特別な Capability は MVP では不要）。
- [ ] **App Store Connect アプリ作成**:
  - プライマリ言語: 日本語
  - カテゴリ: **ヘルスケア／フィットネス**（サブ: **仕事効率化**）
  - サポート URL: 作成したお問い合わせ Google フォームの URL を登録
  - 年齢制限指定: `4+`（UGC 要素はあるがアプリ外閲覧専用かつフィルタリング済みの整理方針を確認し、審査指摘時は `12+` 調整も許容）
- [ ] **課金設定（In-App Purchases）**:
  - サブスクリプショングループ: `Kumogakure Hermit Pro`
  - 月額: `app.kumogakure.pro.monthly`（¥300 / 月・即課金）
  - 年額: `app.kumogakure.pro.yearly`（¥2,400 / 年・**初回オファー：7 日間無料トライアル付与**）
  - StoreKit 審査用スクリーンショット（Paywall S-07）を登録。
- [ ] **銀行口座・税務情報（Paid Apps Agreement）**: 有効化済みであること（未完了だと Sandbox 購入すら失敗する）。
- [ ] **RevenueCat 連携**: App Store Connect API Key（In-App Purchase Key & App Store Connect API Key）を RevenueCat ダッシュボードに登録し、Entitlement `hermit_pro` / Offering `default` のマッピングを完了。

## 2. App Review Guidelines 要注意ポイント対策

| ガイドライン | リスク・審査観点 | 『雲隠れ』での対策 |
| :--- | :--- | :--- |
| **3.1.2 サブスクリプション表示義務** | 価格・自動更新・解約方法・規約リンクが不十分だとリジェクトされる | S-07 ペイウォール画面内に「課金間隔と動的価格」「自動更新と 24 時間前解約の明記」「購入を復元ボタン」「利用規約・プライバシーポリシーへのリンク」をすべて配置（[../01-product/monetization.md](../01-product/monetization.md)）。 |
| **1.2 User Generated Content (UGC)** | ユーザーが自由入力したテキストが Web URL（`/s/{id}`）として公開されるため、UGC 要件が問われる場合がある | ①無料ユーザーはプリセットのみ（自由文言は Pro 限定）②サーバー側 NG ワード＆URL ブロック ③Web ページ `/s/{id}` 下部に「不適切な内容を報告」導線を設置 ④発行から 24 時間で自動失効＆物理削除 ⑤利用規約に禁止事項・削除権限を明記。 |
| **2.5.4 バックグラウンド音声** | `UIBackgroundModes: audio` の不正利用（無音再生でタイマー延命等）と誤認されるとリジェクトされる | 環境音 BGM（雨音・夜風・焚き火）のリアルな再生のみに `AVAudioSession (.playback)` を使用し、タイマー自体は `Date` 差分で計測している旨を **App Review 審査メモ** で明記する（無音時はオーディオセッションを起動しないこと！）。 |
| **4.2 最小機能性（Minimum Functionality）** | 単なるカウントダウンタイマーではリジェクトされるリスク | 独自の多層霧晴れビジュアル演出、環境音再生、画面ロック許容＋他アプリ離脱検知、和モダン画像カード生成、同時雲隠れ人数による連帯体験をスクリーンショット・審査メモで明確に示す。 |
| **5.1.1 データ収集と匿名利用** | 強制ログインや不要な個人情報取得は NG | ログイン不要・完全匿名 UUID で即利用可能。匿名 ID は課金管理・不在証明紐付け目的のみ。 |
| **5.1.2 / ATT（App Tracking Transparency）** | 広告トラッキングや他社データ連携の有無 | 広告 SDK・トラッキング SDK（Firebase/Adjust 等）を一切導入しないため **ATT ポップアップは不要**（`NSUserTrackingUsageDescription` も記載しない）。 |

> **最重要実装チェック（2.5.4 対策）**: 環境音 `sound_id == "none"`（またはユーザーが一時停止中）の場合は **`AVAudioSession.setActive(true)` や無音ファイルのバックグラウンド再生を絶対に行わないこと**。Apple はバックグラウンド延命目的の無音オーディオ再生を厳しくリジェクトします。

## 3. App Privacy（プライバシー栄養表示ラベル）回答ガイド

App Store Connect の「App のプライバシー」アンケート想定回答（外部トラッキングなし前提）:

- **データを収集しますか？**: **はい**（ただし以下の最小限のみ）
  1. **購入履歴（Purchase History）**:
     - 用途: **App の機能（App Functionality）**（Pro プラン判定のため RevenueCat が処理）
     - ユーザーに関連付けられるか: **いいえ**（匿名 UUID のみ、個人情報非紐付けの場合）または「はい（匿名アカウントに準ずる扱いなら）」※RevenueCat 公式ガイドに従い、個人特定不能な匿名 ID のみであることを確認して選択する。
     - トラッキングに使用されるか: **いいえ**
  2. **ユーザーコンテンツ（その他のユーザーコンテンツ）** または **識別子（ユーザー ID）**:
     - 不在証明機能を使う任意ユーザーのみサーバーへ `display_name` / `message`（24h 自動削除）および匿名 `user_uuid` を送信する。
     - 用途: **App の機能（App Functionality）**、トラッキング: **いいえ**。

## 4. ASO（アプリストア最適化）メタデータ案

### アプリ名・サブタイトル（日本語）
- **アプリ名**（30 文字上限）: `雲隠れ - デジタルデトックス＆集中タイマー`（21 文字）
- **サブタイトル**（30 文字上限）: `罪悪感ゼロで休める不在証明＆霧晴れ休息アプリ`（22 文字）
- **キーワード**（合計 100 文字以内・カンマ区切り・スペース不要）:
  - `デジタルデトックス,スマホ依存,集中タイマー,SNS疲れ,ポモドーロ,睡眠,休息,環境音,雨音,マインドフルネス,作業用BGM,放置タイマー`（68 文字）

### プロモーションテキスト（170 文字以内）
> 「今から少し世間から離れます」と優雅に宣言できるデジタルデトックスアプリ。LINE や X に貼れる不在証明カードを発行し、霧が晴れてゆく日本の風景と雨音の中で、罪悪感ゼロの静かな休息時間を過ごしませんか。

### 説明文（概要構成）
1. **キャッチコピー**: SNS 疲れ・通知疲れに、罪悪感のないお休みを。
2. **特徴 3 点**: 不在証明カード＆URL、霧が晴れる風景と環境音、同じ時間に向き合う静かな連帯感。
3. **こんな人におすすめ**: 通知を気にせず本を読みたい、寝る前のスマホをやめたい、少し一人になりたい。
4. **隠者プラン（Pro）のご案内**: 価格と解約方法・利用規約・プライバシーポリシー URL。

### スクリーンショット構成案（6.7 インチ & 6.1 インチ等）
1. **1 枚目**: キャッチ「罪悪感ゼロで、世間から姿を消す。」＋ S-03 霧が晴れつつある風景画面
2. **2 枚目**: キャッチ「『今から雲隠れ』をスマートに宣言」＋ S-02 不在証明カード（LINE/X シェアイメージ）
3. **3 枚目**: キャッチ「放置するほど、日本の美しい景色が現れる」＋ 晴天時 S-04 と風景バリエーション
4. **4 枚目**: キャッチ「心地よい雨音・夜風と静かな連帯感」＋ 同時人数バッジ＋環境音選択
5. **5 枚目**: キャッチ「ログイン不要・3 秒で静寂へ」＋ S-01 ホーム＆ S-06 雲隠れ帳

## 5. TestFlight 実機 QA チェックリスト（リリース直前）

シミュレータだけでなく、必ず **実機 iPhone** で以下を全項目テストします。

- [ ] **基本フロー**: 初回起動 → 3 秒以内開始 → 完了 → 雲隠れ帳へ反映されるか。
- [ ] **画面ロック耐性**: パスコード設定済みの実機で雲隠れを開始し、電源ボタンで画面ロック → 3 分後にロック解除してもリセットされていないか（環境音も継続しているか）。
- [ ] **他アプリ離脱検知**: 雲隠れ中にホームへ戻り別アプリを開く → 10 秒警告通知が届くか → 5 秒後に戻ると継続するか → 12 秒後に戻るとリセット（S-05）されるか。
- [ ] **シェアシート保護**: S-02 で X / LINE / メモアプリ等へシェアし、戻るまで 10〜30 秒かかっても離脱ペナルティが発動しないか。
- [ ] **着信・コントロールセンター**: 通知センター・コントロールセンター開閉、音声着信で誤リセットされないか。
- [ ] **環境音・マナーモード**: 端末側面の消音スイッチ ON でも雨音・夜風が鳴り、完了時に 1.5 秒フェードアウト停止するか。「無音」設定時にバックグラウンドオーディオが動いていないか。
- [ ] **機内モード（オフライン）**: 機内モードで開始・完了が完結し、オンライン復帰時に `/finish` が自動再送されるか。
- [ ] **SNS 実機 OGP 展開確認**: `/s/{id}` URL を **LINE トーク（自分メモ）**、**X（下書き/非公開ポスト）**、**Slack/Discord** に貼り、1200x630 の和モダン OGP 画像が文字化けや切れなく展開されるか。
- [ ] **課金 Sandbox テスト**: 月額・年額購入、キャンセル（エラー非表示）、別端末・再インストール後の「購入を復元」、期間満了後の無料フォールバック（7 日以前履歴ロック、ただしデータ保持）。
- [ ] **アクセシビリティ**: VoiceOver ON、Dynamic Type 最大（または拡大）、視差効果を減らす ON で崩れや操作不能がないか。
