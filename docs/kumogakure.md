# プロダクト企画・仕様書：『雲隠れ（Kumogakure）』

## 1. プロダクト概要

### コンセプト
**「罪悪感ゼロで、優雅に世間から姿を消す」デジタルデトックス＆不在証明アプリ**

既存のスクリーンタイム制限アプリが「強制ブロック（罰・我慢）」を前提としているのに対し、『雲隠れ』は**「堂々とSNSや連絡から離れるための大義名分と、静かで美しい休憩時間」**を提供する。

### ターゲットペルソナ
* **メインターゲット：** 20代〜30代のSNS疲れ・通知疲れを感じている層（会社員、クリエイター、学生、HSP気質の人）
* **抱えているペイン：**
  * スマホをダラダラ見てしまうのをやめたいが、既存の集中アプリはストイックすぎて続かない。
  * LINEやSNSの返信を放置することに罪悪感があり、結局通知を気にしてしまう。
  * 「今からちょっと一人になりたい」と周囲にスマートに伝える手段がない。

### 独自の強み（USP）
1. **「不在証明」による免罪符と自然拡散（バイラルループ）：** 雲隠れ開始時に、SNSやLINEにそのまま貼れる「不在証明URL（動的OGP画像付き）」と「和モダンな画像カード」を生成。ユーザーは罪悪感なく離脱でき、シェア自体がアプリの無料広告になる。
2. **「霧が晴れる」逆説的なご褒美UI：** スマホを触らずに放置した時間に応じて、画面を覆っていた濃い霧が少しずつ晴れ、美しい日本の風景が姿を現す。
3. **静かな連帯感：** 画面の隅に「現在、あなたのほかに〇〇人が雲隠れしています」と表示することで、孤独な我慢を心地よい休息に変える。

## 2. コア・ユーザー体験（UXフロー）

1. **決意する（設定）：** 「30分」「2時間」「明日の朝まで」など、雲隠れする時間とテーマ（読書、睡眠、ただ休む等）を選ぶ。ログイン不要（匿名UUID）で起動から3秒で開始できる。
2. **宣言する（シェア・任意）：** 「ただいま雲隠れ中（21:00帰還予定）」の不在証明URLまたは画像を1タップで生成し、LINE・X・Instagramストーリー等へOS標準シェア。スキップして即開始も可能。
3. **姿を消す（デトックス）：** 画面が深い霧に包まれ、放置タイマーが作動する（画面を離脱すると霧がリセットされるForest方式）。環境音（雨音・夜風など）を流すことも可能。
4. **帰還する（報酬・記録）：** 予定時刻になると霧が晴れ、風景が完成する。「おかえりなさい。2時間の静寂を得ました」と表示され、アプリ内の「雲隠れ帳」に記録が残る。

## 4. システムアーキテクチャ & 技術スタック

個人開発における**「固定費ほぼゼロ」「開発の楽しさ」「SNSバズへの耐性」**を両立する構成を採用する。

### 全体構成
* **モバイルアプリ（フロントエンド）：** **SwiftUI（iOS先行）**
  * *選定理由：* 日本市場はiOSの課金率が高く、将来的にLive ActivitiesやScreen Time APIを組み込む際にネイティブが圧倒的に有利なため。（両OS同時展開を優先する場合はFlutterも選択肢）
* **バックエンド API：** **Rust（Axum）**
  * *選定理由：* バイナリが軽量でメモリ消費が少なく、Google Cloud Runのコールドスタートが極めて速いため、スケールゼロ運用と相性が抜群。
* **ホスティング：** **Google Cloud Run**（東京リージョン：`asia-northeast1`）
  * *選定理由：* 無料枠が大きく、アクセスがない時間は自動停止（スケールゼロ）するため月額0円からスタート可能。
* **データベース：** **Turso**（エッジSQLite）
  * *選定理由：* Cloud Runはステートレスでローカルファイルが永続化されないため、SQLite互換かつ無料枠が潤沢なTursoを採用。
* **CDN / キャッシュ：** **Cloudflare（無料プラン）**
  * *選定理由：* 不在証明URLがSNSでシェアされた際のクローラー集中を防ぐため、OGP画像エンドポイントに `Cache-Control` を設定しエッジでキャッシュさせる。
* **課金管理：** **RevenueCat**（月間売上2,500ドルまで無料）

### Rustバックエンドの役割（最小責務）
1. 不在証明セッションの発行・ステータス表示用HTMLの返却
2. 和モダンフォントを用いた動的OGP画像（PNG）の生成（`resvg` または `image` + `ab_glyph`）
3. 現在アクティブな雲隠れセッション数（同時雲隠れ人数）の集計

## 5. バックエンド概要設計（Rust / Axum）

### 主要エンドポイント案

| Method | Path | 役割 | 備考 |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/sessions` | 雲隠れ開始（不在証明ID発行） | 開始時刻・予定終了時刻・表示名(任意)・一言を受け取り、短いIDを返す |
| `POST` | `/api/v1/sessions/:id/finish` | 雲隠れ完了・途中終了の通知 | ステータスを更新し、同時人数カウントから除外 |
| `GET` | `/api/v1/stats/active` | 現在の同時雲隠れ人数を取得 | `ends_at > NOW()` かつ `status = 'active'` の件数を返す |
| `GET` | `/s/:id` | 不在証明Webページ（HTML） | OGPメタタグ（`og:image`等）を含めて返却。失効後は「帰還しました」表示 |
| `GET` | `/ogp/:id.png` | 動的OGP画像の生成・返却 | Cloudflareキャッシュ前提（`Cache-Control: public, max-age=86400`） |

### データベーススキーマ案（Turso / SQLite）

```sql
CREATE TABLE sessions (
    id TEXT PRIMARY KEY,            -- 短いランダム文字列 (例: "a9x2k8")
    user_uuid TEXT NOT NULL,        -- アプリ側で生成した匿名UUID
    display_name TEXT,              -- 任意の表示名 (例: "旅人")
    message TEXT,                   -- 一言メッセージ (例: "読書してきます")
    theme_id TEXT NOT NULL,         -- 選択した風景テーマID
    status TEXT NOT NULL,           -- 'active' | 'completed' | 'canceled'
    started_at INTEGER NOT NULL,    -- UNIXタイムスタンプ
    ends_at INTEGER NOT NULL,       -- 帰還予定のUNIXタイムスタンプ
    expires_at INTEGER NOT NULL     -- レコード自動削除の目安 (24時間後など)
);

CREATE INDEX idx_sessions_active ON sessions (status, ends_at);
```

## 7. マーケティング・初期集客プラン

広告費をかけずに初期ユーザーを獲得するための3つの柱。

1. **プロダクト内蔵バイラル（不在証明URL＆カード）：** 無料ユーザーの生成するOGP画像・カードの下部に、主張しすぎない美しい書体で `雲隠れ - Kumogakure` と記載。フォロワーが検索して流入する自然ループを作る。
2. **X（旧Twitter）での「Build in Public」：** 開発段階から「SNS疲れがひどいので、堂々と姿を消せる『雲隠れ』というアプリをRustとSwiftで作っています」と、霧が晴れるUIの短い動画を定期投稿して初期ファンを作る。
3. **ASO（アプリストア最適化）：**
   * アプリ名案：`雲隠れ - デジタルデトックス＆集中タイマー`
   * 狙うキーワード：`デジタルデトックス`, `スマホ依存`, `集中タイマー`, `SNS疲れ`, `ポモドーロ`, `睡眠`
