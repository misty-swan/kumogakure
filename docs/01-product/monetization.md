# マネタイズ設計・課金仕様書

## 1. 課金モデル方針

「小さく安定した毎月の収入」と心理的ハードルの低さを両立するため、**Freemium + サブスクリプション（月額 / 年額）** を採用します。

- 無料プラン（**旅人**）でもコア体験（タイマー・基本風景・基本環境音・不在証明 URL/カード発行）を十分に体験でき、自然なバイラル拡散に貢献してもらいます。
- 有料プラン（**隠者 / Pro**）では、「より深い没入感（限定風景・環境音）」「スマートな美意識（透かし非表示・限定デザイン・カスタム一言）」「自己の振り返り（全期間履歴・統計）」を解放します。

## 2. 無料プラン vs 有料プラン 機能マトリクス

| 機能項目 | 無料プラン（旅人） | 有料プラン（隠者 / Pro） |
| :--- | :--- | :--- |
| **価格（日本ストア税込）** | 0 円 | **月額 300 円** / **年額 2,400 円**（月換算 200 円・約 33% 割引） |
| **放置タイマー** | 全時間（15 分〜12 時間）利用可能 | 全時間（15 分〜12 時間）利用可能 |
| **風景テーマ（4 種）** | 基本 2 種（`misty_mountain`, `rainy_bamboo`） | **全 4 種**（`moonlit_lake`, `dawn_shrine` を追加解放・今後拡充） |
| **環境音 BGM（3 種+無音）** | 無音 + 基本 2 種（`rain`, `night_wind`） | **無音 + 全 3 種**（`bonfire` 焚き火を追加解放・今後拡充） |
| **不在証明の一言** | プリセット 5 種から選択（表示名のみ任意入力可） | **プリセット + カスタム文言自由入力（最大 40 文字）** |
| **不在証明デザイン** | `washi_classic`（和紙・墨）のみ | **全 3 種**（`sumi_night`, `indigo_mist` を解放） |
| **不在証明の透かし** | 下部に `雲隠れ - Kumogakure` 透かし表示（固定） | **透かし非表示（`hide_watermark: true`）を選択可能** |
| **同時雲隠れ人数表示** | 利用可能 | 利用可能 |
| **雲隠れ帳（履歴）** | **直近 7 日間のみ詳細閲覧可**（累計合計は表示） | **全期間の履歴閲覧 + 曜日/時間帯別の統計グラフ** |

## 3. RevenueCat・App Store Connect 正本定義

### 3.1 識別子一覧（全コード・全ドキュメント統一）

| 項目 | 識別子（正本） | 備考 |
| :--- | :--- | :--- |
| **Bundle ID** | `app.kumogakure.ios`（開発中仮値） | 開発中は `AppConfig` の単一定数で管理し、App Store Connect 登録時（Week 5）に空き確認のうえ最終確定 |
| **Subscription Group** | `Kumogakure Hermit Pro` | 月額・年額を同一グループに所属させアップグレード/ダウングレード対応 |
| **Entitlement ID** | `hermit_pro` | アプリ内・サーバー側ともにこの文字列のみで資格判定 |
| **Offering ID** | `default` | 初期 Paywall 用デフォルト Offering |
| **月額 Product ID** | `app.kumogakure.pro.monthly` | Price Tier: ¥300 / month（自動更新サブスクリプション・即課金） |
| **年額 Product ID** | `app.kumogakure.pro.yearly` | Price Tier: ¥2,400 / year（自動更新サブスクリプション・デフォルト選択推奨） |
| **無料トライアル** | **年額プランのみ 7 日間無料トライアル付与** | 月額プランはトライアルなし（StoreKit `introductoryOffer` として設定・確定済） |

### 3.2 匿名ユーザー ID 連携
- iOS アプリは Keychain に保存した匿名 UUID v4（`user_uuid`）を使って `Purchases.configure(withAPIKey: ..., appUserID: userUUID)` を初期化します。
- 機種変更時は新端末で別の `user_uuid` が生成されますが、Apple ID が同一であれば「購入を復元（Restore Purchases）」をタップすることで `Purchases.shared.restorePurchases()` が働き、RevenueCat 側で新 `appUserID` へレシート権利が付け替え・共有（Transfer ポリシー）されます。

### 3.3 サーバーサイド資格検証
クライアント側だけの判定を悪用した不正リクエスト（例：`hide_watermark: true` の偽装送信）を防ぐため、バックエンドでも検証を行います。
1. `POST /api/v1/sessions` に Pro 専用パラメータ（`theme_id` が `moonlit_lake`/`dawn_shrine`、`card_style` が `sumi_night`/`indigo_mist`、`hide_watermark: true`、または `is_custom_message: true`）が含まれる場合、Rust バックエンドは `GET https://api.revenuecat.com/v1/subscribers/{user_uuid}` を呼び出します（タイムアウト 2 秒）。
2. `subscriber.entitlements.hermit_pro.expires_date` が現在時刻より未来（または `null` で無期限）であることを確認します。
3. 未課金であれば `403 Forbidden`（エラーコード `PRO_REQUIRED`）を返却します。
4. **フェイルセーフ**: RevenueCat API がタイムアウトまたは 5xx エラーの場合、ユーザー体験を損なわないよう当該リクエストのみ警告ログを出力して許可（Fail-Open）するか、短時間キャッシュを返します（詳細は [../03-architecture/backend-spec.md](../03-architecture/backend-spec.md) 参照）。

## 4. Paywall 表示トリガーと UX 設計

強引なポップアップは『雲隠れ』の世界観（静謐・押し付けない）と相性が悪いため、**ユーザーが Pro 限定要素に触れたタイミング**でのみ、和モダンな Paywall（S-07）をシート表示します。

| トリガー箇所 | 具体的なアクション | 表示後の動作 |
| :--- | :--- | :--- |
| **ホーム画面：風景/環境音選択** | 鍵アイコン付きの Pro 素材（`moonlit_lake`, `dawn_shrine`, `bonfire`）をタップ | 選択状態にはせず Paywall を表示。購入完了時はそのまま該当素材を選択状態にする |
| **不在証明作成：デザイン/一言/透かし** | Pro 限定 `card_style`・カスタム一言・透かし非表示トグルをタップ | Paywall を表示。購入完了時はトグル ON / 限定デザインを選択状態にする |
| **雲隠れ帳（履歴）** | 7 日以前のロック行または「統計グラフ」タブをタップ | Paywall を表示。購入完了時は即座にロックを解除し全履歴を描画する |
| **設定画面** | 「隠者プラン（Pro）を見る」をタップ | Paywall（または加入中ステータス表示）を開く |
| **帰還完了後の控えめな案内** | 累計 3 回目の完了後、初回のみ控えめなバナーを表示（1 回閉じたら再表示しない） | タップ時のみ Paywall を開く |

### App Store 審査必須要素（Paywall 内）
Apple Review Guideline 3.1.2 遵守のため、S-07 ペイウォール画面には以下を必ず明記します。
1. プラン名・課金間隔・実際の価格および初回無料トライアル条件（StoreKit `Product.displayPrice` および `introductoryOffer` から動的取得し、年額選択時は「7 日間無料トライアル後、¥2,400/年で自動更新」等を明記）。
2. 自動更新に関する明確な説明（「現在の期間（または無料トライアル期間）終了の 24 時間前までに解約されない限り自動更新されます。設定アプリからいつでも解約できます」）。
3. **「購入を復元（Restore Purchases）」ボタン**（タップしやすい明確な位置）。
4. **利用規約**・**プライバシーポリシー**（および Apple 標準 EULA）へのタップ可能なリンク。

## 5. 解約・猶予期間（Grace Period）・返金時の振る舞い

| 状態 | `hermit_pro` 判定 | アプリの振る舞い |
| :--- | :--- | :--- |
| **通常解約（期間残存中）** | `true`（期限まで） | 期間満了まで全 Pro 機能を利用可能 |
| **期間満了（失効）** | `false` | ・保存されていた Pro 設定（例：`bonfire`）は自動的に無料デフォルト（`rain`）へフォールバック<br>・過去に記録した 7 日以前の履歴データは**削除せず保持**し、UI 上でのみロック表示に戻す（再加入で即復活） |
| **Billing Grace Period** | `true` | App Store Connect で Grace Period を有効化し、決済エラー中も即時機能停止しない |
| **返金（Revoked）** | `false` | 次回起動・Entitlement 更新時に無料プランへ戻る |

## 6. コスト・損益分岐点・MRR シミュレーション

### 固定費（初期）
- Apple Developer Program: 年額 99 USD（約 15,000 円/年 ≒ **月 1,250 円**）
- 独自ドメイン（`.app` 等）: 年額約 1,800〜2,200 円（**月 150〜180 円**）
- インフラ / DB / CDN / RevenueCat: 各社無料枠内により **月額 0 円**（月間売上 2,500 USD まで RevenueCat 無料）
- **合計固定費**: **約 1,400〜1,430 円 / 月**

### 損益分岐点と成長ステップ
前提条件: Apple Small Business Program 適用（手数料 **15%**）、月額/年額ミックス平均単価（ARPU）**250 円/月**、1 人あたり手取り **約 212 円/月**、無料→有料課金率（CVR）**4.0%**。

| **損益分岐点** | **7〜8 人** | 約 1,750〜2,000 円 | 約 1,484〜1,696 円 | 約 175〜200 人 | 固定費回収ライン |
