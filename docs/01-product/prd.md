# プロダクト要件定義書（PRD）：『雲隠れ（Kumogakure）』

## 1. プロダクト概要・ビジョン

### コンセプト
**「罪悪感ゼロで、優雅に世間から姿を消す」デジタルデトックス＆不在証明アプリ**

既存のスクリーンタイム制限や集中アプリが「強制ブロック（罰・我慢）」を前提としているのに対し、『雲隠れ』は**「堂々と SNS や連絡から離れるための大義名分と、静かで美しい休憩時間」**を提供します。

### ターゲットペルソナ
- **プライマリ**: 20 代〜30 代の SNS 疲れ・通知疲れを感じている層（会社員、クリエイター、学生、HSP 気質の人）
- **セカンダリ**: 読書・執筆・入浴・睡眠前にスマホを手放したいが、つい通知を確認してしまう層
- **抱えている課題（ペイン）**:
  1. 既存の集中アプリはストイック・競争志向が強く、挫折時に罪悪感が残る。
  2. LINE や SNS の返信を放置することへの罪悪感から、結局画面を見てしまう。
  3. 「今から一人になりたい」と周囲に角を立てず、かつスマートに伝える手段がない。

### 独自の強み（USP）
1. **「不在証明」による免罪符と自然拡散（バイラルループ）**:
   - 開始時に LINE / X / Instagram 等にそのまま貼れる「不在証明 URL（動的 OGP 画像付き）」と「和モダンな画像カード」を生成。
   - ユーザーは罪悪感なく離脱でき、シェアされた不在証明自体がアプリの自然な認知導線となる。
2. **「霧が晴れる」逆説的なご褒美 UI**:
   - 放置時間に応じて画面を覆う濃い霧がゆっくりと晴れ、和モダンな日本の風景が姿を現す。
3. **静かな連帯感**:
   - 画面の隅に「現在、あなたのほかに ○○ 人が雲隠れしています」を表示し、孤独な我慢を心地よい休息に変える。

## 3. 機能要件（Functional Requirements）

### FR-001: 匿名ユーザー識別と 3 秒開始
- **概要**: アカウント登録・ログイン画面を設けず、起動後すぐにタイマーを開始できる。
- **詳細**:
  - 初回起動時に UUID v4（`user_uuid`）を生成し Keychain に永続化する。
  - ホーム画面に前回選択（またはデフォルト）の時間・目的・風景・環境音をプリセット表示する。
- **受け入れ基準（Acceptance Criteria）**:
  - `Given` 初回起動のユーザーである
  - `When` アプリを起動し、デフォルト設定のまま「雲隠れを始める」をタップする
  - `Then` ログイン要求なしで即座にセッションが開始され、起動〜開始まで 3 秒以内（シェアをスキップした場合）でデトックス画面へ遷移すること。

### FR-002: 時間・テーマ・目的・環境音設定
- **概要**: 15 分〜12 時間の範囲で雲隠れ時間および演出を設定できる。
- **詳細**:
  - プリセット時間: `15分` / `30分` / `1時間` / `2時間` / `明日の朝まで`（ユーザー設定の目標朝時刻〔デフォルト `07:00`、S-08 設定画面で `05:00`〜`10:00` の範囲で変更可能〕までの分数を計算し、`15`〜`720` 分にクランプ）。
  - カスタムピッカー: 15 分〜720 分（15 分刻み）。
  - 目的プリセット（`purpose_id`）: `rest`（ただ休む）, `reading`（読書）, `sleep`（睡眠）, `focus`（集中・作業）, `walk`（散歩・入浴）, `custom`（自由入力：Pro 限定、最大 40 文字）。
  - 表示名（`display_name`）: 任意入力（最大 20 文字）。未入力時はカード上で省略または「旅人」等の定型表記なし（プライバシー重視）。
  - 風景（`theme_id`）: `misty_mountain`, `rainy_bamboo`（無料）／`moonlit_lake`, `dawn_shrine`（Pro）。
  - 環境音（`sound_id`）: `none`, `rain`, `night_wind`（無料）／`bonfire`（Pro）。
- **受け入れ基準**:
  - `Given` 目標朝時刻がデフォルト `07:00` に設定されており、23:30 にユーザーが「明日の朝まで」を選択した
  - `When` 予定時刻を確認する
  - `Then` 翌朝 07:00（7 時間 30 分 = 450 分後）が帰還予定時刻として設定・明示されること。
  - `Given` 目標朝時刻が `07:00` の状態で、15:00 または 06:50 にユーザーが「明日の朝まで」を選択した
  - `When` 予定時刻を確認する
  - `Then` `現在時刻 + 15分 <= 次の目標朝時刻` なら当日、それ以外は翌日を目標とした上で `15`〜`720` 分（最大 12 時間）にクランプされ、実際の帰還予定時刻（例: `上限12時間：03:00 頃帰還`）が UI 上に明示されること（※詳細は [../02-design/ux-and-screens.md](../02-design/ux-and-screens.md) に従う）。

### FR-003: 不在証明の発行とシェア（任意）
- **概要**: セッション開始前に、不在証明 URL および和モダン SNS 画像カードを生成し、OS 標準シェアで共有できる。
- **詳細**:
  - ユーザーが「不在証明を作って始める」を選ぶと、`POST /api/v1/sessions`（`is_public: true`）を呼び出して短い ID（10 文字 nanoid）と `owner_token` を取得する。
  - 不在証明 URL（例: `https://kumogakure.app/s/{id}`）と端末内レンダリング画像カード（1080x1080 または 1080x1920）を `UIActivityViewController` で共有できる。
  - 「シェアせず静かに始める」を選ぶこともでき、その場合 `is_public: false` で匿名人数集計のみ登録する（API 失敗時はオフラインのままローカル開始）。
- **受け入れ基準**:
  - `Given` ユーザーが不在証明ありで開始し、OS シェアシートを開いている
  - `When` LINE または X への共有を完了またはキャンセルしてシートを閉じる
  - `Then` シェア操作中にアプリ離脱ペナルティが誤発動せず、シートが閉じた直後からデトックスタイマーと離脱検知が開始されること。

### FR-004: 霧が晴れるタイマーと離脱検知
- **概要**: 放置時間に応じて霧が晴れ、他アプリへ離脱した場合のみ霧がリセットされる。
- **詳細**:
  - 残り時間と霧の晴天率 `progress`（`0.0`〜`1.0`）は、`plannedEndsAt: Date` と現在時刻の差分で算出する（バックグラウンド復帰時も正確）。
  - **画面ロックの許容**: アプリがバックグラウンドへ移行後、約 1.5 秒以内に `UIApplication.protectedDataWillBecomeUnavailableNotification` が発火した場合は「画面ロック（スリープ）」と判定し、タイマーを継続する。
  - **他アプリ離脱検知**: 画面ロック以外でバックグラウンドへ移行した場合は **10 秒間の猶予期間** を開始し、ローカル通知「霧が濃くなり始めています。10 秒以内に戻ると続けられます」を即時通知する。10 秒以内に復帰しない場合、セッションを `interrupted` として終了し、サーバーへ `canceled` を送信する。
  - **画面オン維持オプション**: 画面内の「画面を点けたまま」トグル ON で `UIApplication.shared.isIdleTimerDisabled = true` を設定可能。
  - **途中帰還**: 「途中帰還する」ボタン → 確認モーダル → 確定で `canceled` 終了。
- **受け入れ基準**:
  - `Given` 雲隠れセッションが進行中（`active`）である
  - `When` ユーザーが端末の電源ボタンで画面をロックし、20 分後にロック解除してアプリへ戻る
  - `Then` セッションはリセットされず継続しており、経過 20 分に応じた霧の晴天率と残り時間が表示されること。
  - `Given` 雲隠れセッションが進行中である
  - `When` ユーザーがホーム画面へ戻り別アプリを開いたまま 15 秒経過する
  - `Then` 10 秒猶予超過によりセッションが `interrupted` に遷移し、再帰還時に「霧の中へ戻りました」画面が表示されること。

### FR-005: 環境音 BGM 再生
- **概要**: 雲隠れ中に選択した環境音をバックグラウンド・マナーモード対応でループ再生する。
- **詳細**:
  - `AVAudioSession` カテゴリを `.playback` に設定し、端末サイレントスイッチ ON 時や画面ロック中もシームレスループ再生する。
  - デトックス画面上の音量／ミュートボタンで即時 ON/OFF 切替できる。
  - セッション完了・途中帰還・離脱確定時にフェードアウトして自動停止する。
- **受け入れ基準**:
  - `Given` 環境音「雨音」を選択し、端末をマナーモードにして開始した
  - `When` 画面をロックして 1 分待つ
  - `Then` 雨音が途切れなくループ再生され、完了時刻に通知とともに停止すること。

### FR-006: 同時雲隠れ人数の表示（静かな連帯感）
- **概要**: 現在同じタイミングで雲隠れ中の人数を取得し、控えめに表示する。
- **詳細**:
  - `GET /api/v1/stats/active` からアクティブセッション数を取得する。
  - `active_count` から自分自身のセッション（進行中の場合は 1）を引いた `others_count` を表示する。
  - `others_count == 0` の場合、「0 人」とは表示せず「いま、深い静寂が広がっています」を表示する。
  - 取得失敗・オフライン時は前回の数値または静寂メッセージを表示し、エラーダイアログを出さない。
- **受け入れ基準**:
  - `Given` API が `active_count: 1` を返し、自分が雲隠れ中である
  - `When` デトックス画面の連帯感バッジを描画する
  - `Then` 「0 人が雲隠れ中」ではなく代替コピーが表示されること。

### FR-007: 帰還完了報酬と「雲隠れ帳」（履歴）
- **概要**: 予定時刻の到達時に完了演出とローカル履歴保存を行う。
- **詳細**:
  - 予定時刻到達時（フォアグラウンド時は自動遷移＋ハプティクス、バックグラウンド時はローカル通知タップまたは復帰時に自動判定）に完了画面を表示し、霧が完全に晴れた風景と累計時間を提示する。
  - 全セッション（完了・途中帰還・離脱）を SwiftData の `DetoxSessionRecord` に永続化する。
  - 完了履歴（「雲隠れ帳」）では、無料ユーザーには直近 7 日間（かつ累計時間・回数の全期間サマリーは閲覧可）、Pro ユーザーには全期間履歴＋統計グラフを表示する。
- **受け入れ基準**:
  - `Given` 無料ユーザーが 10 日前と 2 日前にセッションを完了している
  - `When` 雲隠れ帳を開く
  - `Then` 2 日前の記録は詳細表示され、10 日前の記録箇所には「7 日以前の記録は隠者プランで解放」ロックバナーと Paywall 導線が表示されること。

### FR-008: 不在証明 Web ページと動的 OGP 画像
- **概要**: アプリを持たない相手や SNS クローラーが不在証明 URL を開いた際、状態に応じた Web ページと動的 OGP 画像を返す。
- **詳細**:
  - `GET /s/{id}`: 雲隠れ中（帰還予定時刻・一言・残り目安）／帰還済み／途中帰還／失効済み（`410 Gone`）の各状態を美しい和モダン HTML で返す。
  - `GET /ogp/{id}.png`: 1200x630 PNG を動的生成し、X・LINE・Facebook・Slack 等のクローラーに展開させる。無料ユーザーの場合は下部に控えめな `雲隠れ - Kumogakure` 透かしを入れる。
- **受け入れ基準**:
  - `Given` 公開セッションが発行され、`expires_at` 前である
  - `When` SNS クローラーまたはブラウザが `/s/{id}` および `/ogp/{id}.png` にアクセスする
  - `Then` `og:image` を含む有効な HTML（`noindex, nofollow` 付）と 1200x630 PNG 画像が返却されること。
  - `Given` 非公開セッション（`is_public = false`）または発行から 24 時間超過後のセッション
  - `When` `/s/{id}` にアクセスする
  - `Then` 非公開は `404 Not Found`、24 時間超過は `410 Gone`（美しい失効案内 HTML）が返ること。

### FR-009: サブスクリプション課金（RevenueCat）
- **概要**: 無料プラン（旅人）と有料プラン（隠者 / Pro：月額 300 円・年額 2,400 円）を提供する。
- **詳細**: 詳細は [monetization.md](monetization.md) に準拠。サーバー側でも Pro 限定オプション送信時に資格を検証する。

## 4. 非機能要件（Non-Functional Requirements）

| 区分 | 要件 ID | 目標値・基準 | 測定・担保方法 |
| :--- | :--- | :--- | :--- |
| **UX / 性能** | NFR-001 | アプリ起動（コールドスタート後ホーム表示）から「雲隠れ開始」まで **3 秒以内・2 タップ以内** | ホーム画面への直接配置、ログインレス起動 |

| **可用性・縮退** | NFR-004 | バックエンドまたはネットワーク障害時も、iOS のローカルタイマー・霧・環境音・SNS カード生成は **100% 動作** | サーバー通信の非ブロッキング化と未送信フィニッシュキュー |

| **セキュリティ** | NFR-006 | セッション乗っ取り・XSS・SVG インジェクション・検索エンジンインデックスの防止 | 10 文字 nanoid、`owner_token` ハッシュ検証、Askama エスケープ、`noindex` |
| **プライバシー** | NFR-007 | 個人特定情報（氏名・メール・位置情報・広告 ID）を一切収集せず、公開セッションも **24 時間で自動失効・削除** | 匿名 UUID、TTL + `/internal/cleanup` 物理削除 |
| **アクセシビリティ** | NFR-008 | WCAG AA 相当のコントラスト比確保、Dynamic Type・VoiceOver・視差効果を減らす（Reduce Motion）対応 | [../02-design/design-system.md](../02-design/design-system.md) に準拠 |

## 5. 成功指標（KPI）

リリース初期（ローンチ〜3 か月）に以下を計測・検証します。

| 指標カテゴリ | KPI | MVP 目標（3 か月以内） | 計測手段 |
| :--- | :--- | :--- | :--- |
| **利用定着** | セッション完了率（`completed / started`） | **65% 以上** | iOS ローカル集計 / サーバー `status` 集計 |
| **バイラル性** | 不在証明シェア率（URL or カード生成割合） | **25% 以上** | `is_public = true` 比率・シェア完了トリガー |
| **集客効率** | 不在証明ページからのストアリンククリック率 | **5% 以上** | `/s/{id}` CTA クリック計測（UTM 付与） |
| **収益化** | 月間アクティブユーザーに対する課金率（CVR） | **4.0% 以上**（Step 1: 有料 50 人 / MRR 約 10,600 円） | RevenueCat ダッシュボード |
| **安定性** | iOS クラッシュフリーセッション率 / API 5xx 率 | **99.5% 以上** / **0.1% 未満** | Xcode Organizer / Cloud Monitoring |

> **プライバシー配慮**: サードパーティの行動トラッキング SDK（Firebase Analytics 等）は MVP では導入せず（App Store Privacy ラベルを最小限かつクリーンに保つため）、サーバー集計および RevenueCat / App Store Connect の標準指標で KPI を追跡します。
