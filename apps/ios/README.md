# Kumogakure iOS App (`apps/ios`)

iOS 17.0+ / Swift 5.10+ / SwiftUI ネイティブアプリ（Week 3〜4 で Xcode プロジェクトおよび Swift ソースを構築予定）。

## 現在の配置済み構成（Week 1）

- `Kumogakure/Resources/Assets.xcassets/Landscapes/` — 風景アセット 4 種（`misty_mountain`, `rainy_bamboo`, `moonlit_lake`, `dawn_shrine`, `1290x2796` JPEG）
- `Kumogakure/Resources/Sounds/` — 環境音アセット 3 種（`rain.m4a`, `night_wind.m4a`, `bonfire.m4a`, AAC-LC 44.1kHz Stereo 128kbps `-19 LUFS` シームレスループ）
- `Kumogakure/Resources/ASSETS_CREDITS.md` — 画像・音声アセットの生成記録およびライセンス・出典台帳

詳細仕様は [../../docs/03-architecture/ios-app-spec.md](../../docs/03-architecture/ios-app-spec.md) および [../../docs/02-design/design-system.md](../../docs/02-design/design-system.md) を参照してください。
